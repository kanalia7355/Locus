     - ページ切替時に見出し（`h1`）へフォーカスを移し、キーボード・読み上げ利用者が

     - 出典ダイアログの Tab トラップを `button` 限定から「実際にフォーカスできる要素全部」

     - モバイル幅（<768px）で開いたサイドバーを Escape で閉じ、サイドバー操作ボタンへ
       フォーカスを戻すようにした（フォーカスがある場合のみ）。
     - 入力欄（composer textarea）のフォーカス表示が `1px #dcdedc`（白背景で 1.35:1）で
       事実上不可視だったため、他コントロールと同じ既存フォーカス色 `--color-focus` 2px に変更。
     - `.visually-hidden` ユーティリティが未定義で、資料一覧ページの検索ラベル「資料を検索」が
       常時表示され（意図と反する余分なラベル、placeholder と重複）、ユーティリティを
       CSS に定義して視覚的に隠し、アクセシブル名は既存の `aria-label` に一本化した。
     - 同一名が繰り返される行操作（資料行の「取消／公開先／削除」、履歴行の「削除」）に
       `aria-describedby` で対象名（資料名・会話名）を付与。**アクセシブル名は変更していない**
       ため既存 E2E のロケータ（`name: "公開先"` 等）は影響を受けない。
  3. `frontend/e2e/a11y.spec.ts`（5 テスト）を新規追加し、上記の回帰を防止する。
