- The local-only rule is unchanged

No security regression.

- Batches so each invocation's joined command line stays under `max_length`
- No path is dropped at a boundary — batches concatenate back into the input
- The threshold is injectable via `max_length` parameter for testing across environments

The modified `scan()` runs the scanner per batch and combines findings via `findings.update()`.
