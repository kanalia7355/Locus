# Task `T-PH2-002`: プロジェクトメンバー実効権限プレビューにおける委任権限の明示と表示整合

## TASK DEFINITION (Assigned by Orchestrator)

- **Requirement IDs**: `IAM-011`, `IAM-012`, `IAM-014`
- **Worktree / Branch**: `task/T-PH2-002` (base: `phase/2-authz`)
- **Allowed Paths**:
  - `backend/app/service.py`
  - `frontend/src/AdminSettings.tsx`
  - `tests/test_admin_project_storage_load.py`
  - `tests/test_concurrent_roles.py`
  - `frontend/src/AdminSettings.test.tsx`
  - `progress/phase-2-authz/tasks/T-PH2-002.md`
- **Implementation Details**:
  1. **実効権限プレビューにおけるロール権限・委任権限・明示的拒否の整合 (`IAM-014`)**:
     - 現在、`backend/app/service.py` の `admin_projects`（671〜677行目）および `membership_roles`（1803〜1809行目）は、`effective_permissions` として `self._permissions(...)`（ロールの和集合 ＋ 有効な委任権限 − 明示的拒否）を返している。
     - 一方、`frontend/src/AdminSettings.tsx`（303行目）では `実効権限（各ロールの和集合、拒否を適用後）: ...` と表示しており、一時的な委任によって付与されている権限（`delegated_permissions`）が含まれている場合でも「各ロールの和集合」としか表示されないため、管理者が「ロール自体に権限がある」のか「一時委任で権限が付与されている」のかをプレビュー上で判別できない。
  2. **バックエンド・フロントエンドの改善**:
     - `backend/app/service.py` の `admin_projects`（の各 member オブジェクト）および `membership_roles` の返却値において、既存の `roles`, `denied_permissions`, `effective_permissions` の後方互換性を完全に保ったまま、現在有効な委任による権限一覧 `delegated_permissions`（ソート済みリスト、または委任がない場合は `[]`）を返すか、または UI 側で委任の寄与が分かるようにする（既存テストの厳密な dict 比較がある場合は、`tests/test_admin_project_storage_load.py` と `tests/test_concurrent_roles.py` の期待値と整合させること）。
     - `frontend/src/AdminSettings.tsx` のメンバー権限表示において、既存の `実効権限（各ロールの和集合、拒否を適用後）` の表示互換性を維持しつつ、`delegated_permissions` が1件以上ある場合は `委任中の権限: <権限名>`（例: `委任中の権限: 資料追加`）を併記して、管理者が実効権限の内訳（ロール・委任・明示的拒否）を誤認しないようにする。
- **Acceptance Criteria**:
  1. プロジェクトメンバーに有効な管理委任がある場合、`membership_roles` / `admin_projects` および `AdminProjects` 画面で、実効権限に加えて委任中の権限が識別可能であること。
  2. 明示的拒否（`denied_permissions`）が設定されている権限は、委任が存在しても `effective_permissions` から確実に除外されることがプレビューでも一貫していること。
  3. 関連するバックエンドテスト `python -m pytest tests/test_admin_project_storage_load.py tests/test_concurrent_roles.py -x -q` およびフロントエンドテスト `npm --prefix frontend test -- --run src/AdminSettings.test.tsx` が全件 PASS すること。
- **Reviewer Model (実装モデルとは別モデルを指定)**: `unassigned`
