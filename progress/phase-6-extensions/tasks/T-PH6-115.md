# Task `T-PH6-115`: チャット領域の上部に注意書きを常時表示する

## TASK DEFINITION (Assigned by Orchestrator)

- **Requirement IDs**: UI 方針。オーナー指示 2026-11-17
  「チャットエリアの上部に中央詰めで『Locusは間違えることがあります。重要な情報は
  確認してください。』と常に表示したらいいんじゃない」。
- **Background**:
  - 資料に根拠のない質問にも答えてよい、という決定が入った（`T-PH6-114`）。
    そうすると、出典の付かない回答が同じ画面に並ぶ。
  - いまは回答ごとのフットノート（「検索で抽出した原文です。AI生成の回答ではありません。
    判断には元資料を確認してください。」）しかなく、**回答を読み終えるまで目に入らない**。
    画面上部の常時表示なら、読み始める前に目に入る。
  - この注意書きは `T-PH6-114` を待たずに出してよい（いまの回答も検索由来で、
    誤りうることに変わりはない）。
- **Implementation Details**:
  1. チャット領域の上部に、**中央詰め**で次の 1 行を常時表示する。
     `Locusは間違えることがあります。重要な情報は確認してください。`
  2. 控えめな見た目にする。淡色・小さめの文字。枠や背景色で主張させない
     （毎回目に入るものが騒がしいと、やがて誰も読まなくなる）。
  3. 会話をスクロールしても消えないこと。入力欄の固定（`T-PH6-111`）と干渉しないこと。
  4. 回答ごとの既存のフットノートは**消さない**。あれは出典と生成方法の説明で、
     この注意書きとは役割が違う。
  5. 絵文字・警告アイコンを付けない（オーナー指示 2026-11-17）。
  6. 読み上げで繰り返し読まれて邪魔にならないよう、`aria-live` は付けない
     （静的な注意書きであって、更新される状態ではない）。
- **Acceptance Criteria**:
  1. チャット画面に上記の文言がそのまま表示される（文言の一字一句を確認するテスト）。
  2. 会話を伸ばしても表示が残ることを確認するテストがある。
  3. 既存の回答フットノートが残っていることを確認するテストがある。
  4. `npm --prefix frontend run test` と `typecheck` が PASS。既存テストに退行がない。
  5. 変更は許可パス内に収まる。既存テストの削除・緩和は禁止。
