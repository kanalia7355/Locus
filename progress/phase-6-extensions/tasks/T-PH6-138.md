## 決めてほしいこと

### (1) PDF の抽出に何を使うか

- **A（当番の推奨）: `pypdf`。** 純 python で、外部の実行ファイルが要らない。
  サンドボックスの子プロセスの中で動く。テキスト層のある PDF から
  本文とページ番号が取れる。**スキャン画像だけの PDF からは何も取れない**
  （それは OCR の話で (2) に属する）。
- **B: `pdfminer.six`。** 版組みの再現は上だが重く、依存も増える。
- **C: 外部の実行ファイル（`pdftotext` など）を呼ぶ。** 入れるものが
  python の外になるので、機械ごとの前提が増える。推奨しない。

### (2) 画像をどう扱うか

ここは**ライブラリの選択ではなく製品の決定**である。

- **A（当番の推奨）: 画像は受け入れるが、OCR はしない。** 添付として
  保存し、本文としては空のまま、出典には「画像」として残す。
  検索には出ないが、**嘘の本文を作らない。**
- **B: OCR する（`pytesseract` + Pillow）。** `pytesseract` は
  **`tesseract` という python の外の実行ファイルを要求する。**
  つまり `T-PH6-135` の docker と同じ形の「機械の用意」が増え、
  入っていない機械では**静かに空の結果**になる。
  やるなら「入っていないことを検知して、入っていないと言う」ところまで
  含めて起票する必要がある。
- **C: 画像は受け入れない。** オーナーの 23:16 の指示に反するので、
  これを選ぶ場合はその旨の指示が要る。

### (3) 版を固定するために、PyPI を引く許可

固定する版は**実在する版でなければならない**。`psycopg` の件が実例で、
ワーカーの `psycopg[binary]==2.9.9` は実在しない組み合わせだった。
**実在を確かめるには PyPI に問い合わせる必要があり、これは外部への
送信である。** `AGENTS.md` の線に従い、**明示の許可を頂いてから**行う。
許可が出れば当番が版を確かめ、この票に書いてから `pyproject.toml` と
`backend/requirements.lock` を当番が直す（保護パスなので当番の仕事になる）。
