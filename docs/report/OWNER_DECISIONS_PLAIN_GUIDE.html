  2. 利用権（lease）の使用記録（誰のどの利用権が、いつ、どの実行端末で使われたか）

10. AIが書いたプログラムを動かして図を作るときの安全対策

フェーズ：phase-6-extensions / 関連する作業：T-PH6-104、T-PH6-114

ひとことで言うと

AIが書いたプログラムを動かして図を作る機能（B：コード実行）は、ファイルの中身を読むだけの解析よりも危険度が一段高いため、専用の厳しい制限を追加して作ります。

残る弱点や注意点

ファイル解析は「攻撃者が選んだ『データ』を読む」だけなのに対し、作図は「AIモデルが書いた『命令』をそのまま動かす」ため、より踏み込んだ危険な境界になります。そのため、T-PH6-104 で作っている隔離の仕組みをそのまま使い回すだけでは不十分です。

開発側が取る対策と今後の扱い

作図用として次の4つの制限を追加する前提で進め、これらを T-PH6-114 の合格条件に入れます。

  1. 動かすのはAIが作ったプログラムだけにして、利用者の元の資料は「読み取り専用（書き換え禁止）」で渡す
  2. 外に出してよい結果は「画像1枚」と「画面への文字出力（標準出力）」だけに限る
  3. インターネットや外部への通信（ネットワーク）は遮断する
  4. 動かせる時間の上限とメモリの量は、作図用に別枠で決める
申し送り（報告）
