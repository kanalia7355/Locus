1. 記録に出てくる言葉の意味（凡例）

段階: phase-6-extensions 種別: 凡例

元の記録では、次の4つの印で役割を分けています。

  • 【解釈】: 開発チームが従うルール

  • 【申し送り】: 開発側がそのままでは気になっている点、または確認してほしい点

2. 通行証の有効期限（TTL）が長いことへの対策

段階: phase-6-extensions 種別: 申し送り

通行証の有効期限（TTL：使える時間）が長いほど、万が一その通行証が外に漏れたときに「他人に使われてしまう時間」も長くなります。

そこで開発側では、通行証をあとから無効にする仕組み（取消：revoke）と「いつ・誰が使ったか」の利用履歴の記録を必ず入れる方針で進めます。なお、有効期限を短くしたいという指示があれば、いつでも設定で変えられます。

3. 同じ社内ネットワーク（LAN）内での安全対策

段階: phase-6-extensions 種別: 申し送り

「同じ社内ネットワーク（LAN）の中だから攻撃は起きない」という前提には、開発側としては同意していません。LAN の中でも、乗っ取られたパソコンや持ち込み端末、同じ LAN 内の別部署からアクセスされる可能性はあります。

ただし、対策にどれだけ費用や手間をかけるかはオーナーの判断であるため、大がかりな確認手続き（重い相互認証）は入れずに進めます。その代わり、ほとんど費用がかからず効果がある次の2つだけを入れます。

  1. 作業を実行する機械（Runner）を登録するときの、1回限りの合言葉
  2. 利用権（lease）の利用記録（誰のどの利用権が、いつ、どの実行機械で使われたか）

この2つは、将来さらに本人確認を厳しくしたくなったときの土台にもなります。

4. 危ないファイルを共有ツールで開くことへの対策

段階: phase-6-extensions 種別: 申し送り

「危ないデータを入れるのは本人のせい」という考え方が成り立つのは、被害が本人だけに閉じる場合だけです。Locus はみんなで使う共有ツールなので、悪意のあるファイルが開かれた瞬間に、サーバー側（つまり全員の資料）へ被害が広がる恐れがあります。

そのため、隔離された安全な箱（サンドボックス）の中で処理する仕組みを取り入れ、その安全策があることを前提にして「いろいろなファイルを広く受け入れる」方針を実装します。

5. 同時に動かす枠（スロット）を増やすときの制限

段階: phase-6-extensions 種別: 申し送り

同時に動かせる枠（スロット）を増やすと、それに比例してメモリや画像処理装置（GPU）の消費量が増えます。実際に動かせる上限の数（N）は、設置する実機（パソコンやサーバー）の性能によって決まります。

そのため、上限 N は設定値のままにしておき、起動するときに実機の性能を測って、もし無理な数になっていたら警告を出すようにします。

6. 二段階認証（MFA）を「不要」にしたことへの代わりの対策

段階: phase-6-extensions 種別: 申し送り

二段階認証（MFA：パスワードに加えて別の確認をする仕組み）は、2026-11-09 の記録では「本番では必須」とされていましたが、2026-11-16 のオーナー判断で「不要」に変わりました。これにあわせて、該当する要件（IAM-005）は「実装しない」扱いに改めます。

ただし、ID とパスワードだけになると、パスワードが漏れたときにすべての資料を見られてしまう弱点が残ります。そこで、代わりに次の4つを初期設定（既定）にします。

  • パスワードに最低限の強さを求める
  • ログインに何度も失敗したら一時的にロックする
  • 新しく発行したときや、管理者がリセットした後の初回ログインでは必ずパスワードを変えさせる（must_rotate。定期的な変更を強制するものではありません）
  • ログイン履歴を管理者が見られるようにする

8. 作図のためにプログラムを動かす機能（B）の安全ルール

段階: phase-6-extensions 種別: 申し送り

選択肢 B（プログラムを実行して図を作る機能）は、ファイルを読み取るだけの「ファイル解析」よりも危険な一歩踏み込んだ仕組みになります。ファイル解析は「誰かが選んだデータを読む」だけですが、作図は「AI モデルが書いた命令を実際に動かす」ためです。

そのため、T-PH6-104 で決めた安全ルールをそのまま使い回すのではなく、作図用（T-PH6-114 の合格条件）として次の4つを追加する前提で進めます。

  • 実行するのは AI が作ったコードだけにし、利用者の元の資料は「見るだけ（読み取り専用）」で渡す
  • 結果として出せるのは、画像1枚と文字の出力（標準出力）だけに限る
  • インターネットなどの通信（ネットワーク）は遮断する
  • 動かせる時間とメモリの量を、作図専用に別枠で制限する

段階: phase-6-extensions 種別: 申し送り
