  • 作業の許可証（リース / lease）の利用記録（誰のどの許可証が、いつ、どの Runner で使われたか）

選べるやり方

4. 共有ツールで危険なファイルを開くときの隔離の仕組み

段階：phase-6-extensions

ひとことで言うと

Locus は全員で使う共有ツールなので、危険なファイルによる被害が全員の資料に広がらないよう、隔離する仕組み（サンドボックス）を前提に「広く許容」を作るという報告です。

いまどうなっているの

「危ないデータを入れるのは本人のせい」という考え方は、被害が本人の範囲にとどまる場合にしか成り立ちません。Locus は共有ツールであるため、悪意のあるファイルが開かれた瞬間に、全員の資料が置かれている中心のコンピュータ（サーバ側）へ被害が及ぶ可能性があります。

決めないとどうなるの

この項目は決めてもらうものではなく報告です。その危険を埋めるためにサンドボックス（危険な動きを外に広げないための隔離された部屋のような仕組み）を採用し、それを前提として「広く許容」という方針を実装します。

選べるやり方

選択肢は示されていません（オーナーの決定どおりに進めるための報告です）。

決める前に知っておくこと

共有ツールである以上、1人が開いた危険なファイルの影響が全員の資料に及ぶリスクがあります。サンドボックスの採用は、その差を埋めるための前提条件となっています。

5. 同時実行の枠（スロット）を増やすときの性能と警告

段階：phase-6-extensions

ひとことで言うと

同時に動かす作業の枠（スロット）を増やすと機械の負荷も比例して増えるため、設定値 N はそのままにし、起動時に機械の性能を測って超えていたら警告を出すという報告です。

いまどうなっているの

同時に動かせる作業の枠（スロット）を増やすと、作業に使う一時的な記憶場所（メモリ）や、計算を高速に処理する部品（GPU）の消費量が比例して増えます。いくつまで動かせるか（N の上限）は、実際にシステムを置いて動かす機械（配備先の実機）の性能によって決まります。

決めないとどうなるの

この項目は決めてもらうものではなく報告です。枠の数（N）は設定で決める値のままにしておき、プログラムを動かすとき（起動時）に実際の機械で性能を測って、上限を超えていたら警告を出す形で進めます。

選べるやり方

選択肢は示されていません（オーナーの決定どおりに進めるための報告です）。

決める前に知っておくこと

スロットを増やすほどメモリと GPU の消費が比例して増えるため、動かす機械の性能によって上限が決まります。

いまどうなっているの

決めないとどうなるの

この項目は決めてもらうものではなく報告です。ID とパスワードだけを使う場合、パスワードが漏れるとそのまま全資料を見られてしまうため、代わりに次の4つを初期設定（既定）にして進めます。

  • パスワードに最低限の強さを求めること

  • 既存にある仕組み must_rotate（アカウント発行時と、管理者がリセットした後の初回ログインで、必ずパスワードを変更させる仕組み。定期的な変更を強制するものではありません）

選択肢は示されていません（オーナーの決定どおりに進めるための報告です）。

決める前に知っておくこと

ID とパスワードのみの運用では、パスワードの流出がそのまま全資料の閲覧につながるリスクがあります。また、must_rotate は定期的なパスワード変更を強制するものではありません。

8. 図を作るためのプログラム実行の安全対策

段階：phase-6-extensions

ひとことで言うと

いまどうなっているの

ファイルを読み取って調べるだけの「解析」は「攻撃者が選んだデータを読む」ことですが、図を作るための「コード実行（プログラムを動かすこと）」は「モデル（AI など）が書いた命令を実際に実行する」ことになり、より踏み込んだ境界になります。そのため、T-PH6-104 の安全の境界をそのまま使い回すことはしません。

決めないとどうなるの

この項目は決めてもらうものではなく報告です。作図用（T-PH6-114 の完成と認める条件）として、次の前提を追加して進めます。

  • 実行するのは生成されたプログラムだけにし、利用者の資料の原本は見るだけで書き換えられない状態（読み取り専用）で渡す
  • 出力は画像 1 枚と文字の出力（標準出力）だけに限る
  • ネットワークは遮断する
  • 実行時間とメモリ（作業用の記憶場所）の上限は作図用に別の枠を設ける

選べるやり方

選択肢は示されていません（オーナーの決定どおりに進めるための報告です）。

決める前に知っておくこと

プログラムの命令を実行する機能は、データを読むだけの機能よりも危険が深くなるため、ネットワーク遮断や出力制限など、作図専用の厳しい条件を付けて進めます。
