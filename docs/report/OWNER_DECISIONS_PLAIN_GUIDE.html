オーナーの決定と、残る弱点

コード実行（B：プログラムを動かして処理する仕組み）は、ファイルを読み取るだけの「ファイル解析」よりも一歩踏み込んだ危険な境界になります。ファイル解析は「攻撃者が選んだデータを読む」だけですが、作図は「AIモデルが書いた命令（プログラム）を実際に動かす」ため、被害が広がりやすくなります。

開発側が追加する対策

T-PH6-104 の安全な枠組みをそのまま使い回すのではなく、作図用（T-PH6-114 の合格条件）として次の4つの制限を追加する前提で進めます。

  1. 動かすのは作られたコードだけにし、利用者の元の資料は「読むだけ（書き換え禁止）」で渡す。
  2. 外に出せる結果は「画像 1 枚」と「画面への文字出力（標準出力）」だけに限る。
  3. 外部やインターネットへの通信（ネットワーク）は遮断する。
  4. 動かせる時間と使えるメモリの上限は、作図専用の別枠にする。
