# ADR 0001 — Open decisions
Status: proposed
- Local deployment OS/containerization and whether multi-tenant deployment is required for MVP.
- PostgreSQL+pgvector vs alternatives; GraphRAG storage and performance tradeoffs.
- Authentication lifecycle, account recovery, MFA, delegated admin model.
- Model choices, licensing, offline dependencies, GPU/CPU resource requirements.
- Cloud data classification/egress policy, auditing and retention.
- Reviewer backend (fresh Claude session, Codex, or other), actual cost/timeout enforcement and hook compatibility.
Do not silently decide security-critical items.
