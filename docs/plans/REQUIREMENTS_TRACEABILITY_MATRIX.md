**How to read:** Each row lists source/authority, phase and implementation job, inspected implementation/configuration paths and method, test evidence, independent review evidence, unchanged gap state, and closure/remaining work. `V` means a direct, read-only source/test/path spot-check in the AUD-2 worktree (file and symbol/test named); `S` means source/document mapping only; `U` means no implementation evidence was verified. Counts are reported only when the cited record states a scoped count. `not verified` is deliberate, not an inferred pass. The explicit `V` rows exceed the required 25 spot checks.
