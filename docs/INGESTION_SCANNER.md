# 取り込みスキャナーの最小接続案（未承認）

現在は `UnavailableScanner` が検査を通過させず、アップロードを隔離します。
合成サンプル投入と実モデルRAGの成功は、実ファイルの検査成功を意味しません。
この案は既存の `Scanner.scan(content) -> bool`、取り込みキュー、送信前・公開前の
権限検証を再利用して、任意のClamAVアダプターを追加するものです。

## 実装対象と境界

- 既定は未接続のまま。サーバー所有者の `LOCUS_SCANNER=clamav` が明示された場合だけ
  アダプターを選びます。未知の設定値は起動を拒否します。HTTPから選択できません。
- 送信先は同一PCの固定TCP `127.0.0.1:3310`。任意ホスト・ポート・URL・ファイルパスを
  受け付けません。本文をメモリから `zINSTREAM` で一度だけ送信します。
- 既存のUTF-8 txt/md/csv・256KiB上限を維持します。ローカル一時本文ファイル、
  shell・外部コマンド・パーサー・モデル呼出し・APIキーは追加しません。
- 接続から応答完了まで総10秒、応答最大1KiB。残り時間を各ソケット操作にも適用し、
  自動再送しません。同時要求はアダプターinstance内で1件。非blockingロックの競合は
  通信せず不通過とし、追加の待ち行列は作りません。daemon全体や別プロセスの
  同時実行数を制限する保証ではありません。
- アダプターも接続前に非空の文字列とUTF-8符号化後262144 bytes以内を検証します。
  符号化不能・上限超過は通信せず不通過とします。
- 4バイトのネットワーク順のチャンク長と終端長0で送信し、非セッション応答をEOFまで
  受信します。完全な単一の `stream: OK` とNUL終端だけを成功にします。
  検出・接続不能・期限切れ・サイズ超過・不正応答・不確定結果はすべて隔離します。
- 既存のキュー件数制限、検査中の削除・キャンセル・権限失効時の公開拒否を維持します。
  新しい設定で既存の隔離資料を自動的に再検査・公開しません。
- 本文、ファイル名、スキャナーの生応答・検出名をログへ保存しません。
  隔離理由は検査不通過の一般的な説明とし、未接続と実検出を誤って断定しません。

## 変わる保証と前提

有効化後は、アップロード本文をLocusのプロセス外のローカル検査サービスにも渡します。
ClamAVのTCPは認証・暗号化を提供しません。管理者が同一PC上の正しいdaemonを管理し、
信頼できないローカル利用者やネットワークから隔離する前提です。単にループバックへ
接続することを、検査サービスの真正性や外部通信禁止の証明とはしません。
Locusの10秒制限はdaemonのCPU・メモリ消費や処理停止を保証しません。
悪意あるデータの完全検出、本番データ保護・保存期間・パーサー安全性を証明しません。

## 今回求める承認範囲

アダプター・明示設定のオフライン実装、合成ソケット／模擬応答のQA、独立レビュー。
実ソフトの導入、daemonの設定・起動、外部からの署名データ取得、実サービス接続、
実研究資料・ウイルス検証ファイルの投入、LAN公開は含みません。

受入条件は、正しいフレーミング・上限・分割応答・EOF・期限・排他・後始末、
未知／異常応答の隔離、既定無効・設定誤り時の拒否、本文／生応答の非記録です。
NUL前後の追加byte、複数応答、途中EOF、EOF未到達の時間切れを隔離します。
成功・失敗・例外経路でロックとソケットを解放することを模擬検証します。
権限失効済みジョブは通信0件、検査中の失効は索引化0件とし、既存QAを維持します。
実検査と署名の鮮度・環境の隔離は、後で所有者承認の実機検証を必要とします。
