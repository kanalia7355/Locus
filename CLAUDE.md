# Claude Code entrypoint
Follow `AGENTS.md` and all linked policy files. Before any task, perform requirement critique, write acceptance criteria, implement with tests, verify and report evidence. Subagents are permitted for ticket drafting, investigation and design drafts (owner instruction 2026-11-17, confirmed 2026-11-25 E5 in `docs/plans/OWNER_DECISIONS_2026-11-25-ENTRIES.md`). Three limits hold and are not negotiable: the model that implemented a job never reviews it; the orchestrator reads a subagent's output before it enters the repository; a subagent never makes an owner decision. Routine implementation still defaults to one agent, and an independent read-only reviewer is permitted after reviewing scope and cost. Do not install or run remote scripts without inspecting and obtaining approval.
